# 绿色出行规划 —— 方法论(参考)

本文件是 `low-carbon-travel-skill` 的详细执行规范。SKILL.md 是概览,本文件是"为什么这么做"和"怎么做对"。

## 1. 数据源选择(为什么用这些)

| 数据 | 提供方 | 选择理由 |
|------|--------|----------|
| 路线(公交/地铁/骑行/步行/自驾) | 高德 Web 服务 API(transit v3、bicycling v4、walking v3、driving v3) | 每种方式独立取得路网、距离、时长和 polyline |
| 起终点坐标(消歧) | 高德 地理编码(geocode/geo) | 国内地址/POI 解析准确 |
| 用户定位 | 浏览器 geolocation → Nominatim/IP/画像 | 3 层 fallback,拿到精确坐标 + 城市 |
| 天气 | Open-Meteo(免费,无 key) | 免费、稳定,有 current_weather |
| 地图展示 | 高德 JS API(AMap.Map) / 高德静态图 | 真实路网、可交互 |

## 2. 完整处理链路

```
用户消息
 → 意图识别(出行/路线触发词)
 → best_location(浏览器/画像/IP) → 精确坐标 + 城市 + detail
 → geocode 城市消歧(防"国贸→新疆")
 → 查天气(Open-Meteo,必查)
 → travel_planning 工具:
     高德 geocode(用户城市) → 距离校验 → 公交+骑行+自驾+短途步行
     + 天气(影响骑行/步行) → 多因素评分 → 详细走法(steps)
 → 输出:推荐 + 备选 + 走法 + 天气 + 地图/导航
```

## 3. 多因素评分公式

```
score = carbon*0.4 + cost*0.2 + duration*0.2 + weather*0.2
```
- `carbon` = 1 - (碳排/最大碳排)
- `cost` = 1 - (费用/最大费用)
- `duration` = 1 - (时长/最大时长)
- `weather` = 1 - 天气惩罚(仅骑行/步行受影响)

**修正(避免鸡肋)**:
- 骑行 `distance_km > 8` → `score *= 0.6`(不推荐全程长途骑)
- 地铁/公交 `步行>1000米` → `score *= 0.75`(首末段步行过长,建议共享单车接驳)
- 天气惩罚 `>0.5` → 直接**排除该露天方式**(雨/雪/大风不推骑行/步行)

## 4. 天气与出行决策

| 天气 | 决策 |
|------|------|
| 晴/多云 | 可推荐骑行/步行,尤其短途 |
| 小雨 | 骑行/步行降分,提醒带伞 |
| 中大雨/雪/大风 | **不推荐**骑行/步行,优先公交/地铁/自驾 |
| 高温/严寒 | 露天方式降分 |

## 5. 城市消歧(关键防错)

无城市名的 POI(如"国贸")用 `city=None` geocode 可能解析到远处(如新疆)。
- 用**用户真实城市**做 geocode 提示;
- 距离校验:起终点 >300km **或** 目的地距用户坐标 >150km → 判为误判,换用户城市重试并取更短组合。

## 6. MCP(mock)的正确用法

- `mock_weather / mock_carbon / mock_echo` 是 MCP 测试桩;**只能用于开发/测试**,返回"当前/22°C"等假数据。
- **真实出行规划不要用它们**。真实数据只来自 `travel_planning` 工具(高德 + Open-Meteo)。
- 若 LLM 误选 mock_weather,应纠正为 `travel_planning`。

## 7. 失败降级与边界

| 场景 | 处理 |
|------|------|
| 高德失败(无 key/限流/没路线) | 返回失败码和空 routes；不生成或估算具体路线、时间、票价、地图几何与碳排 |
| 定位失败 | 用画像城市/IP/默认北京;origin 标"当前位置"时用可得的城市 |
| 天气查不到 | `weather=None`,不影响推荐(骑行/步行无天气惩罚) |
| 两端点太近/无直达 | 仅在高德步行/骑行接口真实返回路径时展示 |
| 中长途骑行 | 降分,不推荐全程骑 |

## 8. 前端展示

- 高德 JS 交互地图(AMap.Map):各方案**不同颜色**,点卡片**重画高亮**;
- 高德静态图 + SVG 折线作为降级(无 JS key / 非 HTTPS 安全上下文时);
- `steps`(详细走法)用文本呈现,"🚗 高德导航"按钮跳转高德 app/网页导航。
