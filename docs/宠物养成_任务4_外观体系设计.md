```python
def determine_appearance(total_co2_saved: float, level: int) -> str:
    """任务4: 根据累计减排 + 等级判定形态(双约束)"""
    if total_co2_saved >= 2000 and level >= 50:
        return "mythic"
    if total_co2_saved >= 1000 and level >= 40:
        return "legend"
    if total_co2_saved >= 200 and level >= 20:
        return "guardian"
    if total_co2_saved >= 100 and level >= 10:
        return "leaf"
    if total_co2_saved >= 30 and level >= 5:
        return "sprout"
    return "seed"
```

### 2.2 解锁逻辑

```python
HABITAT_UNLOCKS = [
    {"id": "green_house", "co2_min": 0, "consec_days_min": 0},
    {"id": "solar_house", "co2_min": 150, "consec_days_min": 7},
    {"id": "forest_camp", "co2_min": 400, "consec_days_min": 30},
    {"id": "carbon_neutral", "co2_min": 1000, "consec_days_min": 100},
]

def check_habitat_unlock(pet_state):
    for h in HABITAT_UNLOCKS:
        if (pet_state.total_co2_saved >= h["co2_min"]
            and pet_state.consecutive_days >= h["consec_days_min"]):
            yield h["id"]
```

## 六、解锁事件流(端到端)

```
用户完成 100 kg 减排
    ↓
PetEngine.apply_behavior_rewards()
    ↓
total_co2_saved 更新 → 200
    ↓
check_appearance_unlock() → "guardian"
    ↓
check_habitat_unlock() → "solar_house"(若 consec_days ≥ 7)
    ↓
check_achievements() → "achv_carbon_saver_100"
    ↓
update_codex() → 各 codex 进度 +1
    ↓
收集所有解锁项
    ↓
推送通知: "🎉 你的精灵进化了 + 解锁光伏小屋 + 获得碳减排百公斤徽章!"
    ↓
```
