# 任务 16: 500 错误堆栈调查与修复 — 报告

**调查时间**: 2026-06-14
**问题来源**: 用户截图显示 500 Internal Server Error

## 一、根因诊断

### 1) trace_id 未生效
- 57 个 ERROR 行的 trace_id **全部是 "-"**
- 原因: P5-B 的 `ContextVar` 没在 `_dispatch` 入口调用 `set_trace_id()`
- 影响: 客户端报错无法关联到具体日志行,排障困难

### 2) Scheduler 每日 KB 更新静默失败
- 日志:`[Scheduler] 每日知识更新失败: KnowledgeUpdater.process_updates() missing 1 required positional argument: 'results'`
- 原因: `scheduler.py:33` 调 `updater.process_updates()` 无参,但定义是 `process_updates(self, results: List[UpdateResult])`
- 正确调用:`results = check_updates(); process_updates(results)`
- 影响: P5 上线后日 KB 更新从未真正跑过,知识库 v7 之后没自动增量

## 二、修复内容

### 修复 A: trace_id 链路
`src/server/app.py`:
- `_dispatch` 入口:`set_trace_id(new_trace_id())` + 保存 token
- `_dispatch` 出口:`finally: reset_trace_id(token)` 防止污染下一个请求
- `send_json` 响应头加 `X-Trace-Id`(客户端可贴给运维)

### 修复 B: Scheduler 每日 KB 更新
`src/scheduler.py`:
- `_daily_kb_update()` 改:`results = check_updates(); process_updates(results)`
- 注释说明根因(P5 遗留 bug)
