## 三、主动技能(用户点击触发)

### 3.1 `skill_score_card`(一键成绩单)
- **触发**: 精灵动作按钮 → "查看我的低碳成绩单"
- **输出**:
  ```
  ┌──────────────────────────────┐
  │  🌟 你的低碳成绩单            │
  ├──────────────────────────────┤
  │  等级: 守护者 (Lv 22)         │
  │  累计减排: 215.3 kg CO2e     │
  │  相当于种 3.6 棵树 🌳         │
  │  本周排名: TOP 12%            │
  └──────────────────────────────┘
  ```
- **实现**:
  ```python
  def skill_score_card(user_id):
      state = pet_engine.get_state(user_id)
      trees = state.total_co2_saved / 60  # 1 棵树年吸 60kg
      return PetScoreCard(level=state.level, co2=state.total_co2_saved, trees=trees)
  ```
- **冷却**: 1 次/天

### 3.2 `skill_share_poster`(分享海报)
- **触发**: 精灵按钮 → "生成环保海报"
- **输出**: PNG 图片(用 PIL 拼)
  - 底图: 碳中和家园背景
  - 主角: 精灵
  - 文案: "我已减排 215 kg,排名 TOP 12%"
  - 二维码: 扫码进入 agent
- **实现**:
  ```python
  def skill_share_poster(user_id):
      state = pet_engine.get_state(user_id)
      img = render_poster(state, appearance=state.appearance)
      img.save(f"/tmp/poster_{user_id}_{int(time.time())}.png")
      return img_url
  ```
- **冷却**: 1 次/天

### 3.3 `skill_lifetime_impact`(长期累计)
- **触发**: 主动技能按钮
- **输出**:
  - 累计减排 = X kg
  - 相当于: 种 N 棵树 / 给 M 辆电动车充电 / N 部手机充 X 次电
  - 个人排名 / 全国排名
  - 时间轴(从第一次低碳行为到今天)
- **冷却**: 1 次/周

### 3.4 `skill_today_summary`(今日复盘)
- **触发**: 主动按钮
- **输出**:
  - 今日减排 / 今日行为数
  - 距离今日上限还差多少
  - 今日最佳行动
- **冷却**: 任意(只读)

## 四、高阶技能(等级解锁,复用 RAG)

### 4.1 `advanced_carbon_footprint`(碳足迹分析)
- **解锁等级**: Lv 15
- **触发**: 主动按钮 + 选时间段
- **实现**:
  - 查 `carbon_footprint_log`(原有表,0 改)
  - 按月/季度/年度聚合
  - 调 RAG 检索知识库,推荐减排建议
  ```python
  def advanced_carbon_footprint(user_id, period):
      log = carbon_log.query(user_id, period)
      aggregation = aggregate_by_category(log)
      # 复用 RAGEngine
      rag_results = rag_engine.retrieve(f"如何减少 {top_category} 排放", top_k=3)
      return CarbonFootprintReport(
          aggregation=aggregation,
          rag_suggestions=[r.content for r in rag_results]
      )
  ```
- **冷却**: 3 次/天

### 4.2 `advanced_personalized_advice`(个性化推荐)
- **解锁等级**: Lv 25
- **触发**: 主动按钮
- **实现**:
  - 读 `personalized_recommender` 已有逻辑(0 改)
  - 调 RAG 增强:
    - 用户偏好(从 user_profile 读)
    - 知识库检索
    - 精灵话术包装
  ```python
  def advanced_personalized_advice(user_id):
      profile = user_profile_manager.get_profile(user_id)
      behavior_summary = behavior_tracker.get_recent(user_id, days=7)
      # 复用
      recs = personalized_recommender.recommend(profile, behavior_summary)
      # 增强:RAG 提供知识背书
      for r in recs:
          r.evidence = rag_engine.retrieve(r.action, top_k=1)
      return recs
  ```
- **冷却**: 5 次/天
