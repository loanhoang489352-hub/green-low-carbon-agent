## 三、交互流程图

### 3.1 行为→数值池完整链路

```
[用户行为]
   ↓ bus 10km
[BehaviorPersistence.record_event]
   ↓
[CarbonFootprintCalculator.calculate_travel_emission] → 2.0 kg CO2
   ↓
   ├──→ [carbon_footprint_log] (用户碳报表,原有表)
   ↓
[PetEngine.apply_behavior_rewards]
   ├──→ 计算 rewards(查 BEHAVIOR_REWARDS 表)
   ├──→ 应用每日上限
   ├──→ 更新 PetState(hunger/mood/vitality/...)
   ├──→ 检查升级(exp_to_next)
   ├──→ 检查形态变化(APPEARANCE_TIERS)
   ├──→ 检查栖息地解锁(HABITAT_UNLOCKS)
   ├──→ 检查成就(ACHIEVEMENTS)
   ├──→ 更新图鉴(CODEX_THRESHOLDS)
   └──→ 写 pet_state_change_log(任务2 主目标)
   ↓
[前端渲染]
   ├──→ 状态动画(SUPER/HEALTHY/HUNGRY/...)
   ├──→ 弹窗通知("精灵进化了!")
   └──→ 数字更新(level/co2 saved/...)
```

### 3.2 对话入口

```
[用户输入]
   ↓ "今天减了多少碳?"
[chat_enhanced handler]
   ├──→ 检测 [pet] 前缀?否 → 走原 LLM 链路
   └──→ 是 → 注入 PetState context → LLM 生成拟人回复
            ↑
       (复用现有 get_llm_client, 0 改造)
```

### 3.3 高阶技能调 RAG

```
[用户点击"碳足迹分析"]
   ↓
[PetEngine.skill_advanced_carbon_footprint]
   ↓
[RAGEngine.retrieve("如何减少出行排放", top_k=3)]  ← 复用,0 改
   ↓
[组装建议 + 精灵话术]
   ↓
[前端展示]
```

## 四、数据表结构(任务 6)

### 4.1 7 张表

```sql
-- 主状态
CREATE TABLE pets (
    user_id TEXT PRIMARY KEY,
    level INTEGER DEFAULT 1,
    exp INTEGER DEFAULT 0,
    hunger INTEGER DEFAULT 50,
    mood INTEGER DEFAULT 50,
    vitality INTEGER DEFAULT 50,
    coins INTEGER DEFAULT 0,
    fragments INTEGER DEFAULT 0,
    appearance TEXT DEFAULT 'seed',
    habitat TEXT DEFAULT 'green_house',
    total_co2_saved REAL DEFAULT 0.0,
    consecutive_days INTEGER DEFAULT 0,
    last_active_date TEXT,
    last_decay_at TEXT,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

-- 状态变更流水(任务2 主目标)
CREATE TABLE pet_state_change_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT,
    behavior_type TEXT,
    amount REAL,
    co2_saved REAL,
    rewards_json TEXT,
    old_state_json TEXT,
    new_state_json TEXT,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

-- 装扮/形态解锁
CREATE TABLE pet_appearance_unlocks (
    user_id TEXT,
    appearance_id TEXT,
    unlocked_at TEXT DEFAULT CURRENT_TIMESTAMP,
    equipped BOOLEAN DEFAULT FALSE,
    PRIMARY KEY (user_id, appearance_id)
);

-- 栖息地解锁
CREATE TABLE pet_habitat_unlocks (
    user_id TEXT,
    habitat_id TEXT,
    unlocked_at TEXT DEFAULT CURRENT_TIMESTAMP,
    current BOOLEAN DEFAULT FALSE,
    PRIMARY KEY (user_id, habitat_id)
);

-- 成就
CREATE TABLE pet_achievements (
    user_id TEXT,
    achievement_id TEXT,
    unlocked_at TEXT DEFAULT CURRENT_TIMESTAMP,
    reward_claimed BOOLEAN DEFAULT FALSE,
    PRIMARY KEY (user_id, achievement_id)
);

-- 技能使用流水
CREATE TABLE pet_skill_uses (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id TEXT,
    skill_id TEXT,
    used_at TEXT DEFAULT CURRENT_TIMESTAMP,
    result_json TEXT
);

-- 图鉴
CREATE TABLE pet_codex (
    user_id TEXT,
    codex_id TEXT,
    unlocked_at TEXT,
    progress INTEGER DEFAULT 0,
    PRIMARY KEY (user_id, codex_id)
);
```

## 五、扩展接口预留(任务 8.2)

### 5.1 多宠物品种(扩展点)

当前只支持 1 个品种"低碳守护精灵"。**扩展点**:

- 在 `APPEARANCE_TIERS` 中按 species 维度拆分
- 在 `pet_appearance_unlocks` 中加 `species` 过滤
- 新建 `pet_species` 表(物种定义)

### 5.2 季节限定皮肤(扩展点)

- 在 `pet_appearance_unlocks.appearance_id` 中加 `season=winter/summer` 标记
- 新建 `seasonal_skins` 表(限时 + 起始日期 + 结束日期)
- 在 `apply_behavior_rewards` 中加季节系数

### 5.3 好友比拼排行榜(扩展点)

- 新建 `pet_friendships` 表(user_id, friend_id, added_at)
- 新建 `pet_leaderboard_cache` 表(weekly_rank, monthly_rank)
- 新建 `/api/pet/leaderboard` 端点
- 复用 `personalized_recommender` 风格(0 改)
- 高阶技能 `advanced_compare_peers` 已在任务 5 预留,实现此端点即可

### 5.4 商城/虚拟商品(扩展点)

- 新建 `pet_shop_items` 表(item_id, name, cost, currency, type)
- 新建 `pet_inventory` 表(user_id, item_id, qty)
- `/api/pet/shop` 端点
- 已实现 `feed()` 函数可复用

### 5.5 宠物社交(扩展点)

- 拜访好友宠物:`/api/pet/visit/{friend_id}`
- 留言:`/api/pet/message/{friend_id}`

### 5.6 数据迁移(未来可优化)
