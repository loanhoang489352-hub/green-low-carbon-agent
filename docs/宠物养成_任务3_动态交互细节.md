## 一、基础实时互动(4 类)

### 1.1 点击抚摸(`pet_pat`)
- **触发**: 前端点击精灵头部/身体
- **效果**:
  - 心情 +2(轻微)
  - 精灵回应动画(眯眼 + 抖动耳朵)
  - 话术:「嘻嘻,好舒服~再摸一下嘛!💚」
- **每日上限**: 30 次(防刷)

### 1.2 投喂低碳道具(`pet_feed`)
- **触发**: 道具栏 → 选道具 → 投喂
- **道具类型 & 效果**:

| 道具 | 消耗 | 饱食 +Δ | 心情 +Δ | 活力 +Δ | 精灵币价格 |
|---|---|---|---|---|---|
| 节能灯泡 | 1 精灵币 | +15 | +3 | 0 | 1 |
| 公交卡 | 1 精灵币 | +5 | +5 | +15 | 1 |
| 太阳能板 | 3 精灵币 | +20 | +8 | +10 | 3 |
| 回收箱 | 2 精灵币 | +10 | +20 | 0 | 2 |
| **碳中和圣果**(限定) | 20 精灵币 | 满 | 满 | 满 | 20(稀有掉落) |

- **精灵回应**:
  - 投喂时: 边吃边说「好香~谢谢你!」
  - 满状态时: 「我吃饱啦,等明天再吃吧~」

### 1.3 对话闲聊(`pet_chat`)
- **触发**: 输入框输入「@pet 你今天好吗?」
- **流程**:
  1. 解析用户输入,识别 @pet 前缀
  2. 调 LLM(复用 chat_enhanced)生成拟人回复
  3. 系统 prompt 注入: 当前精灵状态 + 累计减排 + 本周排行
- **示例回复**:
  - 「我今天心情超好!你也做了 XX kg 的低碳行动,陪我一起继续加油吧!🌟」
  - 「今天我们一起减了 X kg CO2,够给一棵小树呼吸一天啦!🌳」

### 1.4 主动发起低碳小贴士(`pet_tip`)
- **触发条件**: 用户 6h 未互动 + 心情 > 60
- **内容**: 从 RAG 知识库随机抽 1 条低碳小贴士
- **格式**: 精灵话术包装,例如:
  - 「主人,你知道吗?每天少用 1 小时空调,能减 0.5 kg CO2 哦!要我提醒你今晚试试吗?💡」

## 二、状态差异化表现(关键!)

### 2.1 状态分级表

| 状态 | 饱食 | 心情 | 活力 | 表现 |
|---|---|---|---|---|
| **超棒** | ≥80 | ≥80 | ≥80 | 主动播报累计减排 + 推荐新行动 + 跳舞动画 |
| **健康** | ≥50 | ≥50 | ≥50 | 正常站立,主动打招呼 |
| **饿了** | <30 | 任意 | 任意 | 萎靡 + 弹窗「我饿了,做点节能的事吧?」+ 抖动 |
| **难过** | 任意 | <30 | 任意 | 低头 + 提示「陪我聊聊天吧」 |
| **累了** | 任意 | 任意 | <30 | 闭眼 + 提示「我们明天继续吧,早点休息」|
| **危急** | 0 | 0 | 0 | 灰白 + 紧急弹窗「再不照顾我,我要消失了!」 |

### 2.2 弹窗规则(端到端)

```javascript

```

### 2.3 状态音效
- 饱食低: 肚子叫音效
- 心情高: 鸟鸣 + 风铃
- 活力低: 打哈欠

## 四、状态计算与动画映射

### 4.1 精灵状态(综合值)
```
pet_status ∈ {SUPER, HEALTHY, HUNGRY, SAD, TIRED, CRITICAL}
```

```python
def compute_pet_status(hunger, mood, vitality):
    if hunger == 0 and mood == 0 and vitality == 0:
        return "CRITICAL"
    if hunger < 30: return "HUNGRY"
    if mood < 30: return "SAD"
    if vitality < 30: return "TIRED"
    if hunger >= 80 and mood >= 80 and vitality >= 80:
        return "SUPER"
    return "HEALTHY"
```
