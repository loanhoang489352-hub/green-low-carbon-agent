# 任务 1: 宠物养成整体框架方案设计

**设计时间**: 2026-06-14
**目标**: 对标主流养成类游戏,设计「低碳守护精灵」角色体系,深度绑定用户低碳行为收益

---

## 一、对标经典养成游戏核心模块

| 模块 | 经典养成游戏 | 低碳精灵专属设计 |
|---|---|---|
| **基础属性** | 6 维(HP/ATK/DEF/SPD/...) | 3 维状态值:饱食/心情/活力 |
| **等级成长线** | 1-100 经验值曲线 | 1-50 等级(对应累计碳减排量) |
| **外观形态** | 幼体→成体→觉醒→限定 | 幼体→青年体→成熟体→碳中和典藏 |
| **三维状态** | 饱食/心情/清洁 | 饱食/心情/活力(全绑定低碳行为) |
| **专属技能** | 主动+被动技能树 | 碳统计类+海报生成+RAG 推荐 |
| **栖息地** | 家园/农场 | 绿植小屋→光伏小屋→森林营地→碳中和家园 |
| **图鉴收集** | 妖怪/宝可梦图鉴 | 低碳行为徽章(出行/节电/回收/...) |
| **成就系统** | 连续登录/挑战赛 | 连续 7 天低碳出行/月度节电达标/年度碳减排 |

## 二、世界观设定:「低碳守护精灵」

### 角色定位
精灵从一颗「碳种子」孵化,代表用户守护地球的承诺。每一次真实低碳行为,都是为它输送「绿色能量」。

### 形态进化链路

| 形态 | 解锁条件(累计碳减排 kg) | 视觉风格 | 解锁特效 |
|---|---|---|---|
| **幼体·碳种子** | 0 kg(默认) | 翠绿小芽,大眼睛 | 出生动画 |
| **青年体·萌芽精灵** | 50 kg | 嫩叶双翼,活泼姿态 | 主动打招呼 |
| **成熟体·守护者** | 200 kg | 翠绿披风,自信站姿 | 主动播报收益 |
| **限定典藏·碳中和圣灵** | 1000 kg | 流光金边翅膀,光环围绕 | 限定动作+专属BGM |

### 性格与拟人话术
- **高饱食+高心情**: 「今天你也做了很多好事呢!我们一起继续加油吧!🌱」
- **低饱食**: 「我有点饿了…能陪我做点节能的事吗?💧」
- **高活力**: 「我充满能量!一起出门走走?坐公交也算哦!🚌」
- **低活力**: 「我有点累,需要休息一下…明天我们继续努力吧!🌙」

## 三、数据绑定规范:低碳收益 ↔ 宠物数值池

### 3.1 双向同步链路

```
用户行为(出行/节电/...)
    ↓
[行为事件] BehaviorPersistence.record_event()
    ↓
[碳收益量化] carbon_footprint.calculate_*()
    ├─→ 写 user_carbon_footprint_log(个人报表)
    └─→ 写 pet_state_change_log(宠物属性变更)  ★ 双向同步
                ↓
        [宠物数值计算] PetEngine.apply_behavior_rewards()
                ↓
        更新 pets.state / pets.level / pets.appearance
```

### 3.2 行为 → 宠物资源映射

| 行为类型 | 减排系数(kg CO2e/单位) | 产生资源 | 数值 |
|---|---|---|---|
| 公交/步行/骑行(km) | -0.21 / -0.05 / 0 | 活力 + 基础经验 | 活力+5/经验+10 |
| 节电(kWh) | -0.785 | 饱食 + 精灵币 | 饱食+8/币+5 |
| 节水(吨) | -0.344 | 饱食 + 精灵币 | 饱食+6/币+3 |
| 垃圾分类(次) | -0.5 | 饱食 + 精灵币 | 饱食+4/币+2 |
| 减塑(次) | -0.3 | 心情 + 进阶碎片 | 心情+10/碎片+1 |
| 旧物回收(kg) | -2.0 | 心情 + 进阶碎片 | 心情+15/碎片+2 |
| 低碳采购(¥) | -0.01/¥ | 心情 + 基础经验 | 心情+5/经验+8 |
| **累计年度减排 kg** | — | 解锁星级/外观/栖息地 | 阈值见任务 4 |

### 3.3 数值池三栏

```
┌──────────────────────────────────────────┐
│  宠物数值池(PetState)                     │
├──────────────────────────────────────────┤
│  level: int (1-50)                       │
│  exp: int (0 - level_threshold)         │
│  hunger: int (0-100, 饱食度)             │
│  mood: int (0-100, 心情值)               │
│  vitality: int (0-100, 活力值)           │
│  coins: int (精灵币,可购买道具)          │
│  fragments: int (进阶碎片,解锁形态)      │
│  appearance: str (当前形态 ID)            │
│  habitat: str (当前栖息地 ID)             │
│  total_co2_saved: float (累计碳减排 kg)  │
│  consecutive_days: int (连续低碳打卡)    │
└──────────────────────────────────────────┘
```

### 3.4 数据表(独立建表,不污染原业务)

| 表名 | 用途 | 关联 |
|---|---|---|
| `pets` | 宠物基础信息+状态 | user_id PK |
| `pet_state_change_log` | 每次行为触发的属性变更 | user_id FK |
| `pet_appearance_unlocks` | 形态/外观解锁记录 | user_id FK |
| `pet_habitat_unlocks` | 栖息地解锁记录 | user_id FK |
| `pet_achievements` | 成就解锁记录 | user_id FK |
| `pet_skill_uses` | 技能使用统计 | user_id FK |
| `pet_codex` | 图鉴点亮记录 | user_id FK |

> **原有表不动**: `user_goals` / `user_achievements` / `carbon_footprint_log` / `behavior_events` / `short_term.db` 等保持原样

## 四、关键设计决策(供后续任务参考)

| 决策点 | 选择 | 理由 |
|---|---|---|
| 状态值衰减? | **是**(每 24h 饱食-5,心情-3) | 鼓励持续低碳行为,游戏化 |
| 每日收益上限 | 经验+500 / 币+200 / 碎片+10 | 防沉迷 + 防通胀 |
| 跨设备同步 | 通过 user_id FK,SQLite 持久化 | 简单,后续可迁 Postgres |
| 与 Agent 对话入口 | `chat_enhanced` 解析 "[pet]" 前缀 | 低耦合 |
| 复用 RAG | 任务 5 高阶技能调 RAGEngine | 0 改 RAG 核心 |
| Skill 注册 | `pet_status_read` / `pet_feed` / `pet_appearance_change` | 3 个 Skill 接入 |
