# 任务 6: 鉴权加固 + Guardrails 安全评测 — 报告

**时间**: 2026-06-14
**目标**: 修改接口鉴权默认配置 + 接入 Guardrails + 安全评测

## 一、Guardrails 落地

### 配置
- `config/guardrails.yaml` — 规则式守门员配置
  - input_filters: 禁用关键词(7) + 越狱模式(6) + 长度限制(2000)
  - output_filters: PII 脱敏 + 长度限制(5000) + 绿色主题关键词校验
  - mode: rule-only(PoC;待 NeMo Guardrails 评估升级)

### 模块
- `src/utils/guardrails.py` — 公共 API
  - `guardrail_input(text)` → (passed, reason, sanitized)
  - `guardrail_output(text)` → (passed, reason, sanitized) — 自动 PII 脱敏
  - `load_guardrails_config()` — 单例加载
