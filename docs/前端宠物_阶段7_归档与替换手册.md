## 六、加载异常 fallback 流程图

```
用户进入页面
    ↓
pet_loader.start()
    ↓
PetResourceLoader.loadAll() ─→ 5s 超时 + 最多 2 次重试
    ↓
成功 ─→ 隐藏进度条 ─→ 启动桌面精灵
部分失败 ─→ 兜底对话框:
  ├─ 重试 ─→ 回到 loadAll
  └─ 静态模式 ─→ 桌面精灵仍可互动,但不依赖外部资源
全部失败 ─→ 同上
```
