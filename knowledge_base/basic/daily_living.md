# 日常生活减碳指南

## 一、衣 (服饰消费)

### 减碳原则
- **减量购买**: 每生产一件T恤约排放7kg CO2
- **延长寿命**: 衣服每多穿1年可减少约25%的碳足迹
- **理性选择**: 选择环保面料(有机棉、竹纤维、再生聚酯)

### 具体行动
1. 旧衣改造/捐赠
2. 参与衣物的交换/二手交易
3. 选择质量好、耐穿的衣服
4. 使用环保洗涤方式(冷水、减少洗衣频率)

### 碳足迹数据
| 服装类型 | 碳足迹(kg CO2e/件) |
|---------|------------------|
| T恤(棉) | 7-10 |
| 牛仔裤 | 15-30 |
| 外套 | 20-50 |
| 运动鞋 | 10-25 |

## 二、食 (饮食消费)

### 减碳原则
- **植物性饮食**: 肉类(尤其牛肉)碳足迹极高
- **减少浪费**: 全球1/3的食物被浪费
- **本地食材**: 减少运输碳排放
- **季节食材**: 应季蔬果更环保

### 具体行动
1. **每周一天素食**: 可减少约2.5kg CO2/周
2. **光盘行动**: 减少食物浪费
3. **买菜计划**: 按需购买，避免浪费
4. **自带餐具**: 减少一次性餐具使用
5. **减少红肉**: 牛肉碳足迹是鸡肉的4倍

### 食物碳足迹对比
| 食物(1kg) | 碳足迹(kg CO2e) |
|----------|----------------|
| 牛肉 | 27-60 |
| 羊肉 | 20-40 |
| 猪肉 | 7-12 |
| 鸡肉 | 4-7 |
| 鱼肉 | 3-8 |
| 鸡蛋 | 2-4 |
| 蔬菜 | 0.5-2 |
| 水果 | 0.5-2 |

## 三、住 (家居生活)

### 减碳原则
- **节能家电**: 选择能效标识1级产品
- **合理用能**: 人走关灯、拔插头
- **绿色装修**: 环保材料、低VOC涂料
- **垃圾分类**: 减少填埋和焚烧

### 具体行动
1. **空调温度**: 夏季≥26°C，冬季≤20°C
2. ** LED灯**: 相比白炽灯省电80%
3. **拔插头**: 电器待机功耗占家庭10%
4. **绿色出行**: 短距离步行/骑行
5. **节约用水**: 一水多用

### 家电节电参考
| 行为 | 节省电量/年 | 减碳量/年 |
|-----|------------|----------|
| 空调温度调高1°C | ~50kWh | ~40kg CO2 |
| LED灯替代白炽灯 | ~100kWh | ~80kg CO2 |
| 拔掉待机插头 | ~100kWh | ~80kg CO2 |
| 洗衣机满载运行 | ~50kWh | ~40kg CO2 |

---

## 四、行 (交通出行)

### 减碳原则
- **优先步行/骑行**: 零碳排放，还有益健康
- **公共交通**: 地铁/公交比私家车减排80%
- **新能源车**: 电动车全生命周期碳排放比燃油车低50%
- **拼车出行**: 减少空载率

### 具体行动
1. **短距离步行/骑行**: 3公里内首选
2. **公交/地铁**: 中长距离通勤首选
3. **新能源车**: 购车首选
4. **减少飞行**: 短途出行避免飞机
5. **错峰出行**: 减少拥堵和怠速排放

### 出行方式碳排放对比
| 方式(100km) | 碳排放(kg CO2e) |
|------------|---------------|
| 步行/骑行 | 0 |
| 公交车 | 1.5-3 |
| 地铁 | 1-2 |
| 私家车(燃油) | 10-15 |
| 私家车(电动) | 5-8 |
| 国内航班 | 25-40 |
| 国际航班 | 100-200 |

## 五、用 (消费使用)

### 减碳原则
- **减少购买**: 过量消费是碳排放的重要来源
- **选择耐用**: 延长产品使用寿命
- **环保品牌**: 选择有环保承诺的企业
- **包装简约**: 减少过度包装

### 具体行动
1. **自带购物袋**: 拒绝一次性塑料袋
2. **自带水杯**: 拒绝一次性杯具
3. **电子化**: 电子账单、无纸化办公
4. **维修替代购买**: 修修补补再用几年
5. **二手交易**: 闲鱼等平台买卖闲置

### 快消品碳足迹
| 产品 | 碳足迹 | 替代方案 |
|-----|-------|---------|
| 一次性塑料杯 | ~30g CO2e/个 | 不锈钢杯 |
| 一次性纸杯 | ~20g CO2e/个 | 马克杯 |
| 塑料瓶装水 | ~80g CO2e/瓶 | 净水器+水壶 |
| 纸巾 | ~30g CO2e/卷 | 手帕/竹纤维纸 |
