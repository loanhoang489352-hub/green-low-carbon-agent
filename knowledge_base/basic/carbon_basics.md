# 碳中和与碳达峰

## 概念定义

### 碳达峰 (Carbon Peak)
碳达峰是指某个地区或行业的二氧化碳排放量达到历史最高值后，进入逐步下降阶段。这是碳排放由增转降的历史拐点。

**中国目标**: 2030年前实现碳达峰

### 碳中和 (Carbon Neutrality)
碳中和是指通过植树造林、节能减排等途径，抵消自身产生的二氧化碳排放量，实现二氧化碳"净零排放"。

**中国目标**: 2060年前实现碳中和

### 碳足迹 (Carbon Footprint)
碳足迹是指某个产品、服务或活动在其整个生命周期中直接和间接产生的温室气体排放总量，通常以CO2当量(CO2e)表示。

## 核心关系

```
碳达峰 → 碳中和
   ↓
控制排放 → 减少排放 → 吸收中和

时间线:
2020年: 基线年
2030年: 碳达峰
2060年: 碳中和
```

## 日常生活中的碳排放

### 主要来源
1. **交通出行**: 私家车、航空旅行
2. **建筑能耗**: 供暖、制冷、照明
3. **食品生产**: 肉类、乳制品生产
4. **消费购物**: 制造业、物流运输

### 个人碳排放占比估算
- 交通: 约30%
- 建筑: 约25%
- 食品: 约25%
- 其他消费: 约20%

## 减排行动层次

### Level 1: 避免排放 (Avoid)
- 步行/骑行代替开车
- 远程办公减少通勤
- 减少不必要的航空旅行

### Level 2: 减少排放 (Reduce)
- 选择公共交通
- 提高能效
- 减少食物浪费

### Level 3: 替代排放 (Replace)
- 使用可再生能源
- 电动汽车
- 植物性饮食

### Level 4: 碳抵消 (Offset)
- 植树造林
- 购买碳信用
- 支持碳汇项目

## 相关术语

### 温室气体 (GHG)
包括二氧化碳(CO2)、甲烷(CH4)、氧化亚氮(N2O)、氢氟碳化物(HFCs)等。

### 碳强度
单位GDP的二氧化碳排放量，反映经济发展与碳排放的关系。

### 碳汇
通过植树造林、森林管理、土壤固碳等过程吸收大气中的二氧化碳。
