## 二、分区域改造指南

### 客厅

**能耗特点**: 照明+电视+空调是大头

**改造清单**:
1. LED吸顶灯替代白炽灯
2. 智能插座控制待机功耗
3. 变频空调替代定频
4. 隔热窗帘减少空调能耗

**智能方案**:
- 智能音箱+智能插座实现语音控制
- 人体感应实现人来灯亮、人走灯灭
- 温控器实现离家自动关闭

### 卧室

**能耗特点**: 空调+照明+充电器

**改造清单**:
1. 卧室灯改为暖光LED
2. 充电器使用定时插座
3. 选择变频空调
4. 使用阻燃材料的保温窗帘

**睡眠优化**:
- 温度: 24-26°C最舒适省电
- 湿度: 40-60%最佳
- 定时功能: 睡后2小时自动调高温度

### 厨房

**能耗特点**: 冰箱+电磁炉+油烟机

**改造清单**:
1. 选购一级能效冰箱
2. 电磁炉替代燃气(视情况)
3. 节能型抽油烟机
4. 食物残渣处理器(需评估)

**使用技巧**:
- 冰箱留80%空间最省电
- 微波炉比灶具更节能
- 定期除霜减少能耗
- 盖锅盖烹饪减少热量散失

### 卫生间

**能耗特点**: 热水器+浴霸+排气扇

**改造清单**:
1. 空气能热水器替代电热水器
2. LED浴霸替代传统浴霸
3. 低流量花洒(6L/min)
4. 智能插座控制热水器时段

**热水优化**:
- 设置回水器减少冷水等待
- 太阳能+电热组合
- 热水器温度设置55-60°C

## 三、改造实施步骤

### Step 1: 能源审计 (1周)

**工具**:
- 电费账单 (12个月)
- 智能插座监测
- 功耗插座测量仪

**记录内容**:
```
家庭月度用电: __ kWh
峰值时段: ___
主要用电设备: ___
```

### Step 2: 确定优先级 (1天)

**评估维度**:
1. 改造成本
2. 年省电/省钱
3. 回本周期
4. 实施难度

**推荐顺序**:
```
低成本高回报 → 中成本高回报 → 高成本长期回报
```

### Step 3: 分批实施 (3-6个月)

**第一批(第一月)**:
- LED灯全面替换
- 待机能插座改造
- 用电习惯调整

**第二批(第三月)**:
- 空调/热水器升级
- 智能设备部署

**第三批(半年内)**:
- 门窗改造(如需要)
- 光伏安装(如条件允许)

## 四、常见问题

### Q: 改造投入值得吗?
**A**: 
- 基础改造(LED+插座): 投资300元，年省300度电，约240元，回本<2年
- 进阶改造(节能家电): 投资5000元，年省1000度电，约800元，回本5-7年

### Q: 智能设备会不会增加耗电?
**A**: 
- 智能设备本身功耗极低(<1W)
- 通过精细化控制，整体节电10-20%
- 选择知名品牌的智能设备

### Q: 租房能改造吗?
**A**: 
- LED灯: 可携带，搬家可带走
- 智能插座: 可携带
- 节能贴/保温膜: 可粘贴
- 大件改造需与房东协商

### Q: 什么季节改造最好?
**A**: 
- 空调改造: 4-5月(入夏前)
- 门窗改造: 春季或秋季
- 灯具改造: 随时可进行
