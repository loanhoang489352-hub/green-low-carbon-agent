# 上海低碳生活与个人碳账户

> 上海市生态环境局 + 上海市发展改革委 联合推动
> 全国**最早**(2019 起)建立个人碳账户体系的城市之一

## 一、上海个人碳账户(随申办·绿碳)

### 开通方式
- **App**: "随申办"市民云
- **入口**: 首页 → "绿色低碳" → "绿碳生活"
- **注册**: 实名认证后自动开通

### 积分获取行为
| 行为 | 积分 | 换算 |
|---|---|---|
| 公交乘车 | 0.5 积分/次 | 1 元消费券 ≈ 100 积分 |
| 地铁乘车 | 0.3 积分/次 | |
| 共享单车 | 0.2 积分/次 | |
| 步行(>500 步) | 0.1 积分/次 | |
| 新能源车充电 | 1 积分/kWh | |
| 旧物回收 | 5-50 积分/次 | 按品类 |
| 光伏发电(个人户用) | 0.4 积分/kWh | 上网电量 |

### 积分兑换
- 微信/支付宝消费券
- 公交地铁充值卡
- 上海植物园/动物园门票
- 部分品牌绿色商品(可降解餐具、有机食品)

## 二、上海新能源车政策(2024-2025)

### 专用牌照(绿牌)
- 2024-2025 年**继续免费发放**(无拍卖,直接上牌)
- 2023 年起对插电混动(含增程)收紧:**必须满足纯电续航 ≥ 50km**
- 2024 起**纯电里程占比**要求逐步提高

### 置换补贴(2024 加码)
| 条件 | 补贴 |
|---|---|
| 报废或转出名下燃油车 + 购买新能源车 | **1.5 万元** |
| 置换纯电车型(本地叠加) | 2000 元 |
| 个人充电桩建设 | 500 元/桩 |

### 充电桩补贴
- 居住区充电桩示范项目: **500-1000 元/桩**
- 出租车换电站建设: 最高 **30 万元/站**

## 三、上海绿色建筑与家居

### 装配式建筑(2025 目标)
- 外环以内新建商品住宅 **100% 装配式**
- 内环以内旧改优先装配式工艺
- 装配率 ≥ 40% 的项目可享受容积率奖励 3%

### 既有建筑节能改造
- 重点: 老公房、老公寓外墙保温改造
- **居民出资部分**: 30% (政府补贴 70%)
- 改造后: 室内温度夏低 2-3℃,冬高 1-2℃,电费降 15-25%

## 四、上海碳普惠 I·CARE 平台

- **运营方**: 上海环境能源交易所
- **对接行为**: 公交、地铁、共享单车、新能源车、光伏、垃圾分类
- **企业接入**: 京东、美团、饿了么、滴滴等已接入

## 五、上海社区"低碳生活"试点

### 静安区低碳社区(2024-2025)
- 智能垃圾箱房: 投递自动积分
- 社区光伏: 屋顶分布式光伏 + 储能
- 共享充电桩: 错峰充电补贴 0.3 元/度

### 浦东临港新片区
- 100% 绿色建筑(三星级)
- 氢能源公交示范线
- 个人碳积分可兑换临港商业体停车券

## 六、垃圾分类(上海最严)

### 强制分类
- **厨余**: 剩菜剩饭、果皮、茶叶渣
- **可回收物**: 纸张、塑料瓶、玻璃、金属、衣物
- **有害垃圾**: 电池、灯管、药品、油漆
- **干垃圾**: 其他

### 罚款
- 个人: 拒不改正的 **50-200 元/次**
- 单位: **5000-50000 元/次**

### 资源化率
- 2025 目标: 资源化率 **80%**
- 2024 已达: 生活垃圾资源化率 **65%**

## 七、个人行动建议

1. **立刻开"绿碳"账户**: 实名认证,每天签到多得 5 积分
2. **优先公共交通**: 1 公里内步行,3 公里内共享单车,5 公里内公交地铁
3. **家用光伏**: 自发自用 + 上网卖电(0.4 元/度补贴)
4. **家电买一级能效**: 每年省电 200-500 度
5. **厨余垃圾破袋投放**: 配合智能垃圾箱房拿积分
