# 北京市低碳生活与碳普惠

> 北京市生态环境局 + 北京市发改委 联合推动
> 北京市碳普惠平台(全国最早的个人碳普惠平台之一,2018 起)

## 一、北京市碳普惠平台

### 平台入口
- **App / 小程序**: 北京绿色出行一体化服务平台
- **对接地图**: 高德地图、百度地图
- **扫码乘车**: 北京公交、地铁、市郊铁路

### 积分行为
| 行为 | 积分 | 换算 |
|---|---|---|
| 公交乘车 | 10 积分/km | |
| 地铁乘车 | 8 积分/km | |
| 步行(>500 步) | 20 积分/km | |
| 骑行(共享单车) | 15 积分/km | |
| 新能源车充电 | 1 积分/kWh | |
| 旧物回收 | 50-200 积分/件 | |
| 旧家电以旧换新 | 100-500 积分/件 | |

### 积分兑换
- 微信支付券、支付宝消费券
- 公交一卡通充值
- 公园年票(颐和园/动物园/植物园)
- 绿色商品(可降解餐具、有机食品)
- 公益捐赠

## 二、北京新能源车政策(2024-2025)

### 专用牌照(绿牌)
- **新能源车绿牌**: 2024-2025 继续**不限量**
- 燃油车牌照: 摇号(中签率 0.3%-0.5%) + 竞价(均价 2-5 万元)

### 置换补贴(2024 加码)
| 条件 | 补贴 |
|---|---|
| 报废国三以下 + 换新能源 | **2 万 + 1 万(京) = 3 万元** |
| 置换新能源(无报废) | **1 万元** |
| 个人充电桩建设 | 500-1000 元 |
| 单位充电桩建设 | 30% 补贴(最高 500 万) |

### 充电基础设施
- 全市充电桩超 **30 万根**(2024 年,密度全国第一)
- 公共快充: 1-1.5 元/度(峰谷电价)
- **谷电优惠**: 0.3-0.5 元/度(00:00-08:00)
- **超充网络**: 2024 起 800V 高压超充铺开

## 三、北京碳排放权交易(全国最大)

### 北京碳市场
- **运营方**: 北京环境交易所
- **启动**: 2013 年(全国最早 7 个试点之一)
- **覆盖**: 电力、热力、水泥、石化、其他工业、服务业
- **2024 起**: 与全国碳市场并轨
- **个人参与**: 暂不可直接买卖,可通过碳普惠间接参与

### 历史价格
- 2013-2017: 20-50 元/吨
- 2018-2022: 60-100 元/吨
- 2023-2024: 90-150 元/吨
- 2024 年最高: **150 元/吨**

## 五、北京绿色建筑

### 强制标准
- 2025 起: **新建建筑 100% 绿色**(二星及以上)
- 2030 起: 既有公共建筑**全部完成节能改造**

### 装配式建筑
- 全市新建建筑装配率 ≥ 40%
- 商品房: 享受容积率奖励 3%
- 政策补贴: 0.5%-1% 建安成本

### 既有建筑改造
- 老公房外墙保温: **政府补贴 70%** + 个人 30%
- 节能门窗补贴: 户均 5000 元
- 改造后: 夏低 2-3℃,冬高 1-2℃,电费降 15-25%

## 七、北京居民碳排放与建议

### 典型北京居民年排放
| 来源 | 年排放(kg CO2e) | 占比 |
|---|---|---|
| 居住(供暖+用电) | 2500-4000 | 50% |
| 私家车/网约车 | 800-1500 | 22% |
| 餐饮 | 600-1000 | 17% |
| 消费购物 | 400-700 | 9% |
| 其他 | 200-300 | 5% |
| **合计** | **~4500-7500** | **100%** |

### 北京特色减碳建议
1. **冬季供暖清洁化**: 参与"煤改电煤改气"补贴
2. **地铁通勤优先**: 北京地铁全国最长(800+ km),覆盖率高
3. **开新能源车**: 充电桩密度高,日常通勤纯电成本 < 0.1 元/公里
4. **参与碳普惠**: 高德地图绑定"北京绿色出行",扫码乘车自动积分
5. **家电买一级能效**: 每年省电 200-500 度
6. **减少冬季长途出游飞行**: 北京冬季节假日拥堵严重,飞机+长候机楼能耗高

## 八、北京特色行动

### "无车日"
- 每年 9 月 22 日(世界无车日): 鼓励公共交通
- 部分区域限行,免费公交地铁

### 冬季供暖节能
- 设定温度 **≤ 22℃**(国家建议)
- 节能门窗补贴
- 智能温控器: 离人自动降温

### 夏季空调
- 公共建筑 26℃ 强制(2019 起)
- 个人建议 26℃+(每低 1℃ +6% 电费)

### 限塑令(最严)
- 商超禁用一次性塑料袋
- 外卖减塑: 鼓励自带餐具
- 塑料污染罚款 1-10 万
