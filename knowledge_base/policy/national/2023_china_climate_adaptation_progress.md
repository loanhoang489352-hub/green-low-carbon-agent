## 三、《国家适应气候变化战略 2035》核心(背景知识)

### 战略目标

| 时间节点 | 目标 |
|---|---|
| **2025** | 基本完成适应气候变化基础能力建设,适应工作纳入国民经济和社会发展规划 |
| **2030** | 适应气候变化政策体系和体制机制基本形成 |
| **2035** | 气候适应型社会基本建成 |

### 重点领域(7 个)

1. **水资源** - 应对极端降水/干旱
2. **陆地生态系统** - 森林/草原/湿地保护
3. **海洋与海岸带** - 海平面上升/风暴潮
4. **农业与粮食安全** - 极端天气下的稳产
5. **健康与公共卫生** - 高温热浪/传染病
6. **基础设施与重大工程** - 韧性城市/海绵城市
7. **城市与人居环境** - 极端天气避险

### 重点区域(7 个)

1. **东部沿海** - 台风/海平面上升
2. **京津冀** - 高温/雾霾/极寒
3. **长三角** - 复合极端天气
4. **粤港澳大湾区** - 台风/洪涝
5. **黄河流域** - 干旱/水资源
6. **西部生态脆弱区** - 沙漠化/冰川退缩
7. **东北及青藏高原** - 永冻土退化

## 四、2023 进展报告核心内容(基于报告大纲)

> 完整报告需向生态环境部索取,以下为已知大纲

### 1. 政策与制度
- 部门 + 省级适应方案陆续落地
- 跨部门协调机制建立
- 与"双碳" 协同推进

### 2. 重点领域进展
- 水资源:海绵城市试点扩大
- 农业:气候智能农业示范区
- 健康:高温热浪健康预警系统
- 基础设施:韧性城市试点

### 3. 试点示范
- **气候适应型城市试点**(2024-05 公布深化名单)
- 案例: 北京副中心(2025 全球地方气候奖)、深圳海绵城市、武汉应对极端降水

### 4. 国际合作
- 与 UNDP/世行/亚行 合作
- "一带一路"绿色合作
- 南南合作气候适应援助

### 5. 资金机制
- 适应气候变化专项资金
- 绿色金融(适应类绿色债券)
- 国际气候资金

## 五、对企业的实操意义

### 谁应该关注?

1. **基础设施企业**(建筑/交通/水利)
   - 设计标准提高(抗台风/抗洪/抗高温)
   - 韧性投资是新增长点

2. **农业企业**
   - 气候智能农业 → 政府补贴
   - 节水灌溉 / 抗逆品种 → 市场机会

3. **健康/医疗企业**
   - 高温热浪应急服务
   - 传染病预警监测

4. **保险企业**
   - 巨灾保险 → 政策力推
   - 气候风险定价

### 资金机会

- 国家适应气候变化专项资金(财政部+生态环境部 联合)
- 气候适应型城市试点 → 中央补贴
- 适应类绿色债券(中国人民银行支持)

## 六、对个人消费者的意义

### 直接影响

1. **居住安全**
   - 韧性城市试点 → 你的城市更能应对极端天气
   - 海绵城市 → 暴雨内涝减少

2. **健康保障**
   - 高温/寒潮 预警系统更精准
   - 公共空间避险设施完善(冷库/暖库/避难所)

3. **农产品稳定**
   - 极端天气下蔬菜/粮食供应链更韧性
   - 价格波动减小

4. **保险产品**
   - 巨灾保险 → 个人/家庭可买
   - 健康险扩展(高温/雾霾相关疾病)

### 间接影响

5. **就业新方向**
   - 气候适应工程师
   - 韧性城市规划师
   - 气候健康咨询师

6. **公众参与**
   - 气候适应志愿者
   - 社区韧性建设(社区应急队/避难所演练)

## 七、与减缓(碳达峰碳中和)的关系

**适应 vs 减缓**:

| 维度 | 适应 | 减缓 |
|---|---|---|
| 目的 | 降低气候变化伤害 | 降低气候变化速度 |
| 行动 | 增强韧性 | 减少 GHG 排放 |
| 时效 | 应对 **已发生** + 未来气候变化 | 减缓 **未来** 气候变化 |
| 重点 | 区域 / 行业 / 个人 | 能源 / 工业 / 交通 |
| 资金 | 适应基金(国际+国内) | 碳市场 + 绿色金融 |

**协同**: 适应 + 减缓 **缺一不可**,适应是"防守",减缓是"进攻"。
