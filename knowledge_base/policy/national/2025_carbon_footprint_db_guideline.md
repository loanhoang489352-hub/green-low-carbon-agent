# 《产品碳足迹因子数据库建设工作指引》2025 印发

> **七部委联合**: 生态环境部 + 国家发改委 + 工信部 + 住建部 + 交通运输部 + 市场监管总局 + 国家数据局
> 印发日期: 2025-12-12
> **核心**: 指导地方/行业/科研机构/企业 探索 **碳足迹因子数据** 研制与数据库开发

**目的**: 推进产品碳足迹因子 **数据库建设**(为碳足迹核算提供权威基础数据)

## 三、文件性质与意义

### 政策定位

这是中国 **首个** 关于产品碳足迹因子数据库建设的 **官方工作指引**:

1. **多元主体参与**: 鼓励地方/行业协会/科研机构/企业 都来建库
2. **统一规范**: 防止"各自为政"的因子混乱
3. **数据基础设施**: 服务全国碳足迹核算

### 与其他数据库的关系

| 数据库 | 主体 | 性质 |
|---|---|---|
| **国家温室气体排放因子数据库**(NCSC) | 政府(国家级) | 权威基础 |
| **产品碳足迹因子数据库**(本指引) | 多元(地方/行业/企业/科研) | 细分领域 |
| **行业碳足迹数据库** | 行业协会 | 行业自治 |
| **企业 LCA 数据库** | 企业内部 | 自管 |

## 四、对企业的实操指引

### 1. 出口企业(应对 CBAM / 欧盟碳关税)

**关键**: 用 **官方因子库** 而非 IPCC 默认值,可证明数据真实性

**建库参与**:
- 行业龙头联合行业协会 → 建立行业级因子库
- 通过权威认证 → 国际买家认可

### 2. 绿色工厂申报企业

- 必须做产品碳足迹核算
- 使用本指引推荐的因子库 → 加分项

### 3. 数据服务/咨询机构

**商机**:
- 帮地方政府/行业建库
- 数据采集/清洗/质量评估
- 与碳标识认证机构合作

### 4. 科研院所

- 参与 LCA 方法学研究
- 因子库技术标准制定
- 共建共享平台

## 五、技术指引核心(摘要)

> 本部分基于通知配套解读文章

### 1. 数据库建设原则
- **规范性**: 符合 ISO 14067 / PAS 2050 等国际标准
- **可比性**: 因子边界一致,可跨企业/跨地区比较
- **可追溯**: 来源/方法/不确定性 全记录
- **动态更新**: 反映工艺/能源结构变化

### 2. 因子分级
- **国家级因子库**(NCSC):权威基础
- **行业级因子库**:行业协会主导
- **地方级因子库**:省市级特色
- **企业级因子库**:内部数据

### 3. 数据质量
- 一手数据(企业实测)优先
- 二手数据(文献/数据库)兜底
- 不确定性分析

## 七、对个人消费者的最终意义

虽然是基础设施建设,但 **3 年后** 你会感受到:

1. **产品上有"碳标签"** 像营养成分表一样
   - 例: 一瓶水 50g CO₂e / 一件衣服 8kg CO₂e

2. **低碳产品溢价合理化**
   - 真正减排的产品贵在哪一目了然
   - 消费选择有数据支撑

3. **碳普惠精准化**
   - 个人买低碳产品 → 自动积累碳积分
   - 兑换地铁卡/共享单车等

4. **国际贸易畅通**
   - 中国产品出口欧盟不再"被惩罚"
   - 真实低碳 → 真实通行
