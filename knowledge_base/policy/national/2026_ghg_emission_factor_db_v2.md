# 国家温室气体排放因子数据库(第二版)2026 年正式发布

> 国家应对气候变化战略研究和国际合作中心,2026-03-01 发布
> 生态环境部门户网站转发
> **核心**: 排放因子从 285 个 → **576 个**(新增 + 更新 291 个)

## 一、政策依据

- 《关于加快建立统一规范的碳排放统计核算体系实施方案》
- 《完善碳排放统计核算体系工作方案》

**目的**: 持续夯实碳排放统计核算 **数据基础**

## 二、第二版重大升级

### 1. 因子数量大幅扩容

| 版本 | 因子总数 |
|---|---|
| **第一版** | 285 个 |
| **第二版**(2026-03) | **576 个**(+291,增长 **102%**) |

### 2. 新增覆盖范围

| 领域 | 新增因子类型 |
|---|---|
| **能源活动** | 直接排放因子 |
| **工业生产过程** | 直接排放因子 |
| **农业活动** | 直接排放因子 |
| **电力消费** | 间接排放因子 |
| **重点产品碳排放强度** | 粗钢、未锻轧铝 等 |

### 3. 国际化

- **首次** 同步上线 **英文版**
- 服务对外贸易(应对 CBAM / 欧盟碳关税)
- 促进国际交流

**官方网站**: https://data.ncsc.org.cn/factories/index

**使用对象**:
- 企业碳核算
- 第三方核查机构

- 国际贸易碳足迹
- 政府碳统计

## 四、对企业的实操意义

### 谁需要用?

1. **碳市场重点排放单位**(4 行业:发电/钢铁/水泥/铝冶炼)
   - 排放报告核算必备
   - 替代旧因子提高数据精度

2. **产品碳足迹核算企业**
   - 出口企业(CBAM 申报)
   - 绿色工厂申报
   - LCA(生命周期评价)

3. **金融机构**
   - ESG 报告
   - 绿色债券/绿色信贷评估

### 怎么用?

```
登录 → 选行业/产品 → 选时段 → 导出因子表
→ 套用到企业碳核算公式: E = Σ(活动数据 × 排放因子)
```

### 价值点

- ✅ **官方权威**(替代企业用 IPCC 默认因子)
- ✅ **本土化**(中国电网 + 中国生产工艺)
- ✅ **免费 + 可查询**
- ✅ **中英双语**

## 五、对个人消费者的意义

虽然是工具型数据库,但 **影响消费选择**:

1. **产品碳标识** 将基于此因子库
   - 未来商品上可能看到"碳足迹 X kg CO₂e"标签
   - 让消费者用"碳"选购

2. **电力消费间接因子** → 个人碳账户
   - 北京/上海/广州碳普惠平台可对接
   - "我家这个月用电 X 度 → 减排 Y kg"

3. **促进低碳产品** 价格回归
   - 碳标签让真正低碳产品溢价合理化
   - 长期推动绿色消费
