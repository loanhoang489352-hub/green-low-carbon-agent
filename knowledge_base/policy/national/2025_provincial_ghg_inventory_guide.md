# 《省级温室气体清单编制指南(2025 年版)》

> 生态环境部,2026-01-04 印发
> **核心**: 在 2011 年试行版基础上,**重大升级** 省级温室气体清单编制规范

## 一、政策背景

### 1. 为什么要更新?

- **2011 年版** 是 **试行版**,15 年未系统更新
- 期间中国温室气体清单 **方法学/数据/能力** 大幅进步
- 双碳目标提出后,需要更 **科学/规范/可操作** 的省级清单
- IPCC 2019 修订指南 / 国家级清单 v2 已发布,省级需对齐

### 2. 政策依据

- 党的二十大精神
- 《2030 年前碳达峰行动方案》
- 《关于完整准确全面贯彻新发展理念做好碳达峰碳中和工作的意见》
- 《关于加快建立统一规范的碳排放统计核算体系实施方案》

## 二、文件性质

**对象**: 全国各省、自治区、直辖市生态环境厅(局),新疆生产建设兵团生态环境局
**性质**: **指南**(非强制,但实质是省级清单的国家标准)
**作用**: 各地方编制省级温室气体清单 **参考执行**

## 三、清单覆盖范围(IPCC 5 大类)

省级温室气体清单按 **IPCC 国家清单指南** 体系编制,覆盖 5 大类:

| 类别 | 主要源 | 主要 GHG |
|---|---|---|
| **1 能源活动** | 化石燃料燃烧/油气逃逸/煤矿瓦斯 | CO₂, CH₄, N₂O |
| **2 工业生产过程** | 水泥/钢铁/化工/电子半导体 | CO₂, HFCs, PFCs, SF₆ |
| **3 农业活动** | 牲畜肠道发酵/粪便管理/稻田/施肥 | CH₄, N₂O |
| **4 土地利用变化和林业(LULUCF)** | 森林吸收/砍伐/农地转换 | CO₂(吸收) |
| **5 废弃物** | 固体废弃物/废水处理 | CH₄, N₂O |

## 四、与 2011 版的主要变化(基于一般技术演进)

### 1. 方法学对齐 IPCC 2019 修订指南

- 排放因子 → 使用国家温室气体排放因子数据库 v2(2026-03 发布)
- 不确定性 → 引入 IPCC 蒙特卡洛方法
- 关键源识别 → 90% 累积排放阈值

### 2. 数据基础升级

- 与国家统计局年鉴对齐
- 引入电力实测排放因子(分区域电网)
- 农业活动 → 与农业农村部对接
- LULUCF → 与林草局对接

### 3. 行业细分加深

- 工业过程: 新增电子半导体行业 SF₆ / HFC
- 能源: 油气甲烷逃逸更细
- 农业: 反刍动物 vs 单胃动物分类

### 4. 数据公开性

- 鼓励省级清单 **公开发布**(原仅内部)
- 编制过程 + 数据来源 透明
- 与"双控"(能耗双控 → 碳排放双控)挂钩

## 五、对省级政府的实操要求

### 必须做(2026 后)

- ✅ 按新指南编制 **省级温室气体清单**(年度/五年)
- ✅ 提交至生态环境部应对气候变化司
- ✅ 数据来源 + 方法学 + 不确定性 全记录
- ✅ 与省级 GDP/能耗 数据交叉校验

### 推荐做

- 🟡 在省厅官网公开清单
- 🟡 邀请第三方专家评审
- 🟡 与碳达峰行动方案挂钩

## 六、清单编制流程

```
省级人民政府
  ↓ 组织
省级生态环境主管部门
  ↓ 牵头 + 部门协作(发改/工信/统计/农业/林草等)
专业研究机构
  (中国环境科学研究院/省级环科院/高校)
  ↓ 编制
省级温室气体清单(年度/五年版)
  ↓ 评审
专家委员会评审
  ↓ 报送
生态环境部应对气候变化司
  ↓ 汇总
全国温室气体清单 → UNFCCC 国家通报
```

## 七、配套支撑机构(抄送单位)

- **中国环境科学研究院**(CRAES)
- **中国环境监测总站**
- **对外合作与交流中心**
- **环境规划院**
- **国家应对气候变化战略研究和国际合作中心**(NCSC)
- **土壤与农业农村监管生态环境技术中心**

## 八、对企业的间接影响

虽然这是**省级**层面的清单编制,但企业是数据源:

1. **重点排放单位** → 数据上报更规范,与全国碳市场联通
2. **行业协会** → 协助统计行业总量
3. **碳核算服务机构** → 商机扩大(协助省级编制)
4. **绿色金融** → 省级清单 → ESG 评级支撑

## 九、对个人消费者的意义

虽然是政府间技术性文件,但 **3 年后** 你会看到:

1. **省级低碳排行榜** 透明化
   - 你能查到自己省份在全国排第几
   - 推动地方政府减碳竞争

2. **产品碳标签** 有省级数据支撑
   - 不同省份生产的同类产品碳足迹不同
   - 消费者可选择"低碳产地"

3. **碳普惠** 个人账户的"省级权重"
   - 低碳省份的居民可能享受更多绿色信贷优惠
   - 推动绿色消费规模化
